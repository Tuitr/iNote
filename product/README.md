# Продуктовая аналитика: голосовой ассистент в MAX

Продукт iNote · команда «Нейрончики» · обновлено 26.10.2026

## Коротко

- **Проблема.** Дела приходят в неудобный момент — на паре, в дороге, на объекте — и их некуда быстро записать. 70% опрошенных студентов хотя бы иногда пропускали дедлайн, потому что забыли о нём (21 из 30).
- **Для кого.** Основной сегмент MVP — студенты: по ним есть свои данные. Сегмент с самой высокой ценой ошибки — разъездные специалисты, например инженеры технадзора: без освидетельствования скрытых работ следующие работы на объекте запрещены. Это гипотеза, интервью с ними не проводились.
- **Решение.** Бот в MAX и мини-приложение с календарём: надиктовал голосом — бот записал дело, переспросил недостающее, предупредил о пересечении встреч, поправил запись по просьбе, напомнил в срок, показал план и нашёл старую запись по смыслу.
- **Почему сейчас.** 64% россиян пользуются голосовыми сообщениями (ВЦИОМ, 2023). У MAX крупнейшая среднесуточная аудитория среди мессенджеров — 69,9 млн против 33,8 млн у Telegram (Mediascope, август 2026).
- **Конкуренты.** В Telegram голосовые боты-напоминалки есть, но маленькие. В каталогах MAX планировщиков не нашли. Поиск по смыслу не заявлен ни у одного конкурента. Главный риск — Алиса AI в MAX.
- **Экономика.** Около 162 ₽ переменных затрат в месяц на пользователя из MAU: 158 ₽ — GigaChat Max при 6 500 токенах на запрос, меньше 4 ₽ — распознавание в Yandex SpeechKit. Облачный ASR выгоднее своего примерно до 14 тыс. MAU. Экономить нужно на LLM.
- **Риски.** Юридический статус для публикации в MAX, 152-ФЗ о персональных данных, 149-ФЗ об информации, стоимость LLM, Алиса в MAX.

## Только российские сервисы

Все внешние сервисы, которые получают данные пользователей, — российские. Данные пользователей не покидают РФ, что закрывает требование локализации 152-ФЗ, а продукт не зависит от зарубежных платежей.

| Слой | Сервис | Разработчик |
| --- | --- | --- |
| Мессенджер и мини-приложение | [MAX](https://dev.max.ru/docs/webapps/introduction) — национальный мессенджер по 156-ФЗ | VK |
| Распознавание речи | [Yandex SpeechKit](https://aistudio.yandex.ru/docs/ru/speechkit/pricing) | Яндекс |
| Языковая модель | [GigaChat Max](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs) | Сбер |
| Поиск по смыслу | Синонимы от GigaChat + поиск PostgreSQL | Сбер, своя разработка |
| Серверы и база данных | размещение в РФ | — |

## Как читать

Каждый файл начинается с вывода, потом идёт обоснование. У каждой цифры есть источник и дата. Статус помечен явно: **факт** — внешний источник; **наш опрос** — 30 студентов; **допущение** — параметр расчёта, уточняется на пилоте; **гипотеза** — проверяется. Схемы нарисованы в Mermaid и отображаются на GitHub.
