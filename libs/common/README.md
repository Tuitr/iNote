# libs/common — общая библиотека (зона C)

Конфиг, structlog, lifecycle и реестр фоновых задач, health-роутер, HTTP-клиент с таймаутами и повторами,
middleware `X-Trace-Id` и сервисного токена, `WireModel`, хелпер ключей Redis. Нужна всем сервисам.

Импорт: `from common.<модуль> import ...`. Статус: каркас (S0, шаг 1), модули — шаг 2.
