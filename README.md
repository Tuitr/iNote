# iNote — голосовой ассистент для календаря в MAX

iNote — продуктовый проект: готовый к использованию ассистент для личных дел, а не демо одной
технологии. Работает на стенде с настоящими MAX, Yandex SpeechKit и GigaChat.

Бот в MAX: голосом или текстом ставит задачи, напоминания и встречи, отвечает «что у меня завтра»,
ищет старые записи и присылает напоминания; мини-приложение MAX показывает календарь.

## Что умеет

| Сценарий | Пример фразы |
| --- | --- |
| Напоминание | «Напомни завтра в 10 утра позвонить Ивану» |
| Встреча | «Поставь встречу с Иваном в пятницу в 15» |
| Список за период | «Что у меня завтра?», «Какие планы на неделю?» |
| Поиск старых записей | «Найди звонок Ивану», «Когда у меня маникюр?» |

Плюс: уточняет, если не хватает дня или времени («Утра или вечера?»); при пересечении встреч
предлагает свободные окна; понимает «перенеси её на завтра» про последнюю запись; «каждый
понедельник» — повторяющаяся запись; «Отменить», «Выполнено», «Отложить на 1 ч» — кнопками.

## Как попробовать

1. Открыть бота в MAX: <https://max.ru/se14489070_1_bot> и нажать «Начать».
2. Сказать голосом или написать: «Напомни через 2 минуты выпить воды».
3. Спросить «Что у меня сегодня?» и открыть календарь кнопкой «Мой день».

## Архитектура кратко

```
MAX → bot → asr (голос → текст, Yandex SpeechKit)
        → agent + Brain (GigaChat выбирает инструмент) → mcp (8 инструментов) → libs/core → PostgreSQL
scheduler → bot: напоминания вовремя
max_app (мини-приложение) → api (только чтение) → libs/core → PostgreSQL
```

- `user_id` подставляет агент, модель его не видит; подтверждение «записал» строится из ответа
  инструмента, а не из текста модели; даты и обязательные поля проверяет код.
- Redis — дедуп, локи, контекст диалога и кеши; источник правды — PostgreSQL.
- Наружу через Caddy с HTTPS открыты только webhook бота, `/api/v1/*` и статика мини-приложения.

## Стек

| Часть | Технологии |
| --- | --- |
| Бэкенд | Python 3.12, FastAPI, pydantic 2, uv |
| Данные | PostgreSQL 16 (полнотекст, `pg_trgm`), SQLAlchemy 2 + asyncpg, Alembic, Redis 7 |
| Голос и LLM | Yandex SpeechKit, GigaChat (function calling), MCP |
| Мессенджер | MAX Bot API, мини-приложение на React 19, TypeScript, Vite, MAX UI |
| Инфраструктура | Docker Compose, Caddy (HTTPS), GitHub Actions |

## Команда

| Роль | Кто | Зона |
| --- | --- | --- |
| A | Инженер распознавания речи | Голос → текст, Yandex SpeechKit (`services/asr`) |
| B | LLM-инженер | Понимание фраз: Brain, промпт, GigaChat, eval (`libs/brain`) |
| C | Бэкенд-разработчик: бот и агент | Бот MAX, агент, Redis, общая библиотека, стенд (`services/bot`, `services/agent`, `libs/common`, `deploy`) |
| D | Бэкенд-разработчик: данные | База, MCP, API, Scheduler (`libs/core`, `services/mcp`, `services/api`, `services/scheduler`) |
| E | Фронтенд-разработчик | Мини-приложение MAX (`max_app`) |
| F | Продакт-менеджер и аналитик | Сценарии и требования, приоритеты, продуктовая документация (`productDock`) |

## Как запустить

```bash
make install   # зависимости (uv)
make up        # стенд на фейках, без ключей
make e2e       # сценарии ТЗ через фейковый MAX
make down
```

Стенд с настоящими MAX, SpeechKit и GigaChat и выкатка на сервер — в [docs/architecture.md](docs/architecture.md).

## Что улучшили бы

- Голосовой ответ ассистента (синтез речи).
- Изменение и удаление записей прямо в мини-приложении; экраны карточки записи, поиска и истории.
- Уверенность распознавания (SpeechKit v3): переспрашивать, если голос распознан плохо.
- Голосовые длиннее 30 секунд.
- Чистка старых уведомлений и истории диалога.
